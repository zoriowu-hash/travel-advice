# Travel Advice

A personal log of things to consider when travelling — a running checklist of reminders, lessons learned, and pre-trip considerations.

## Organization

- [`checklist.md`](checklist.md) — the running list of things to consider.
- Items are added in the order I think of them; they are **not** grouped by date.
- Longer topic notes can go in `notes/` (one file per topic) as the repo grows.

## Entry format

Each item is a checkbox line so it can be ticked off when handled:

```
- [ ] **Topic** — what to consider or do
```

Example:

```
- [ ] **Passport** — check it is valid for at least 6 months beyond the trip
```
